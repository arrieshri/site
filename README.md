# Сцена

Небольшой сайт на Go: главная со светом, который следует за курсором, регистрация и стена коротких заметок. Пароли и заметки лежат в локальном файле SQLite.

## Запуск

Создать папку,назвав ее site(или как то подобно)
в папке создать еще 3 папки,назвав data,static,templates
в папке data сунуть (scene.db; scene.db-shm; scene.db-wal;)
в папке static сунуть (boot.js; motion.wasm; style.css; wasm_exec.js;)
в папке templates (auth.html; home.html; layout.html;)
Нужен Go 1.26. Команды запускаются из этой папки:

```
go run .
```

Сайт открывается на http://localhost:8080

`PORT` меняет порт (`8080` или `:8080`). `SCENE_DB` задаёт путь к базе. Без неё база создаётся в `data/scene.db`. Каталог `data/` не коммитьте: в нём хеши паролей и текст заметок.

## Движение

Сценарий движения написан на Go (`motion.go`, `motion_js.go`) и собран в `static/motion.wasm`. После правки этих файлов пересоберите его той же версией Go, которой запускаете сайт:

```
go generate
```

`static/wasm_exec.js` копируется из установки Go и должен совпадать с компилятором, который собрал wasm.
